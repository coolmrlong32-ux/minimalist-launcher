# 极简桌面 (Minimalist Launcher · v2.7.0)

一款追求极致流畅与单手人体工学的 Android 原生桌面启动器（Home App），零第三方臃肿库依赖，支持离线拼音/T9 检索、静默圆点与左右镜像流体字母波浪导轨、单手贴底搜索、锚点 Pop-up 浮层与文件夹、内嵌通知胶囊、日出日落护眼壁纸与无障碍手势控制。

## v2.7.0 新特性（原生 Niagara 质感深度重构）
- **贴底单手搜索与键盘精准跟随**：搜索框移至屏幕底端并实时跟随软键盘顶缘，搜索结果与快捷计算自底向上排列，最佳匹配项紧邻大拇指；搜索与全部应用模式下自动收起顶部时钟释放完整可视空间。
- **导轨静默圆点模式与左手镜像波浪**：`NiagaraWaveView` 新增原生 Niagara 风格静默微点（触碰即刻流体展开为高斯波浪字母），左侧边缘升级为真正的本侧镜像展开（静止完全隐形），同时将主列表联动位移收敛至安全区彻底消除左边缘图标裁切。
- **统一锚点文件夹 Pop-up、背景模糊与软键盘避让**：文件夹点击升级为原地锚点弹出的带图标微卡片，与右滑应用 Pop-up 保持一致视觉；Android 12+ 展开浮层自动启用原生 `RenderEffect` 背景模糊，快捷回复弹出软键盘时卡片自动上移避让；右滑跨阈值采用轻脆单次微震取代底部蓝色悬浮提示条。
- **壁纸景深无重影与排版对齐修复**：自绘壁纸改用常态 `1.045 → 1.0` 单次绘制消除搜索过渡重影，系统壁纸在 Android 11+ 接入原生 `setWallpaperZoomOut`；无卡片模式下首页未读通知不再套框错位，同步修复单条清除通知角标残留与媒体进度刷新误清回调 Bug。
- **120Hz 渲染零抖动优化**：缓存文件夹聚合图标、`customIcons` 映射与 `NiagaraCoinButton` 渐变着色器，复用列表项图标 `LayoutParams`，并清理冷启动冗余隐藏视图。

## 核心特性
- **流体字母波浪导轨**：左右双边缘自适应波浪字母检索，动态排除系统返回手势冲突，支持内拉直达首位应用。
- **弹出式文件夹与通知胶囊**：常用应用内嵌未读消息摘要与快捷回复，支持原地展开带图标微卡片文件夹。
- **日出日落护眼调色盘**：6 套昼夜自适应极光壁纸，支持本地天气与农历节气状态展示。
- **纯原生零依赖极速编译**：不依赖重型 Gradle 缓存，通过 `build.ps1`（Windows）、`build.sh`（Linux）或 GitHub Actions 直接调用 `aapt` + `javac` + `d8` 输出签名 APK。

## 云端与本地构建
- **云端自动打包（免费）**：每次推送代码至 `main` 分支或手动触发 `Actions -> Build Android APK`，GitHub Actions 将自动编译并生成 `极简桌面-v2.7.0.apk` 与 `极简桌面-v2.7.0-direct.apk` 供直接下载。
- **AI Agent 协作**：仓库内置 `AGENTS.md` 架构与构建指南，其他 AI Agent 接入仓库后可直接读取完整源码结构并完成修改与验证。
