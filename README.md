# 极简桌面 (Minimalist Launcher · v2.8.0)

一款追求极致流畅与单手人体工学的 Android 原生桌面启动器（Home App），零第三方臃肿库依赖，支持首页一体流（Unified Stream）、App Pop-up 关联子应用集合、动态未读通知浮现、自适应流体字母波浪导轨、120Hz 紧贴软键盘极速搜索、弹出式文件夹、日出日落护眼壁纸与无障碍手势控制。

## v2.8.0 新特性（Niagara 原生灵魂架构全面重构）
- **首页一体流（Unified Stream）与极简顶部一览**：新增 `NiagaraHeaderView` 并将顶部时钟、日期/农历、天气/智能电量、矢量日程/便签、无边框极简媒体条（圆角封面 + 2dp 细进度线）与原生桌面微件整体融入 `ListView` 纵向滚动流；支持 3 种时钟排版风格（经典纤巧 / 现代圆润 / 极简居中）、按需智能电量显示（默认仅充电或 ≤ 20% 浮现）与跨午夜日期/农历实时监听。
- **原生 Niagara 流体波浪导轨全面进化**：支持自适应字母表（仅展示实际存在应用的首字母，可切换完整 A-Z），彻底移除遮挡感大圆球，升级为纯字母本体流体涌出与手指精准偏上对齐；修复左边缘静默态系统侧滑返回手势冲突，缩短触碰启航延迟至 70ms 并取消空字母位误震。
- **统一锚点 Pop-up 体系与 App Pop-up 关联集合**：新增 `PopupCardController` 统一应用右滑、长按与文件夹 Pop-up 交互并淘汰旧版 Emoji 大抽屉；支持为首页任意常用应用挂载 **App Pop-up 关联子应用集合**（右滑原地展开，行尾微弱箭头提示），并支持文件夹点击/右滑展开、重命名、内部拖拽排序及切换「点击直开首应用」。
- **动态未读通知浮现与安全左滑**：非首页应用收到可清除未读通知时自动临时浮现于首页底部，支持点开、右滑快捷回复或左滑瞬清（同步修复批量清除角标残留）；左滑安全化仅在存在未读通知时生效，彻底杜绝误删常用应用。
- **120Hz 贴键盘搜索与搜索体验升级**：Android 11+ 接入 `WindowInsetsAnimation.Callback` 逐帧紧贴输入法升落，悬浮圆钮随搜索进度柔和缩放渐隐；空搜索态清爽呈现 Top 6 最近使用，输入关键词自动高亮命中字符，支持可配置网页搜索引擎（Bing / 百度 / Google / 夸克）与键盘回车一键执行最佳结果。

## 核心特性
- **流体字母波浪导轨**：左右双边缘自适应波浪字母检索，动态排除系统返回手势冲突，支持内拉直达首位应用。
- **App Pop-up、文件夹与动态通知**：常用应用支持关联子应用 Pop-up 与内嵌通知快捷回复，非首页来消息自动浮现。
- **日出日落护眼调色盘**：6 套昼夜自适应极光壁纸，支持本地天气、农历节气与自定义第三方图标包/Niagara Dots。
- **纯原生零依赖极速编译**：不依赖重型 Gradle 缓存，通过 `build.ps1`（Windows）、`build.sh`（Linux）或 GitHub Actions 直接调用 `aapt` + `javac` + `d8` 输出双包名签名 APK（单包 `< 300 KB`）。

## 云端与本地构建
- **云端自动打包与发布 Release（公开仓库免费）**：每次推送或合并更新了版本号的代码至 `main` 分支，或推送 `v*` 标签（如 `v2.8.0`），GitHub Actions 将自动编译并同步创建 **GitHub Release**（附带 `极简桌面-v${versionName}.apk` 与 `极简桌面-v${versionName}-direct.apk` 双安装包）；PR 与手动触发也会生成 Actions 产物。
- **AI Agent 协作**：仓库内置 `AGENTS.md` 架构与构建指南，其他 AI Agent 接入仓库后可直接读取完整源码结构并完成修改与验证。
